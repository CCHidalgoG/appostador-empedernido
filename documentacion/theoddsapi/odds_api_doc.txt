GET historical event odds
Endpoint

More info
The list of events returned in the /odds endpoint mirrors events that are listed by major
bookmakers. This usually includes games for the current round
Events may temporarily become unavailable after a round, before bookmakers begin listing
the next round of games
Events may be unavailable if the sport is not in season. For popular sports, bookmakers
may begin listing new season events a few months in advance
If no events are returned, the request will not count against the usage quota
To determine if an event is in-play, the commence_time can be used. If commence_time is
less than the current time, the event is in-play. The /odds endpoint does not return
completed events
