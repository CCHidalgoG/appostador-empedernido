Squad Ratios & Scores

Models

This endpoint provides Ratio & Score values for individual players on season level, including contextual
information such as position, play duration, and match shares. Each entry contains the list of Ratios & Scores and
their respective values for the given player on a given position within the selected iteration. Players who
appeared in more than one position will have separate entries for each position.
This endpoint provides the Player Scores for a specified position or group of positions. It should only be used
when you want to create custom position groups — for example, combining "DEFENSIVE_MIDFIELD" and
"CENTRAL_MIDFIELD" into one group.
If players are always analyzed by individual positions, the regular player-scores endpoint should be used instead.
That endpoint automatically uses the corresponding peer group for each position and is significantly faster —
requiring only a single request instead of 11 requests to retrieve all players for an iteration.
